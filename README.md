\# ファイルメタデータ解析とSSHログ解析によるデジタルフォレンジック調査ツール（Web版）



卒業研究「デジタルフォレンジックの基礎技術に関する研究」の一環として開発した、

CUI版ツール（\[forensic-tool](https://github.com/ivyc259008kido/forensic-tool)）を

ブラウザから操作できるようにしたWebアプリケーションです。



ファイルのメタデータ・ハッシュ値・拡張子偽装を調査する「ファイル解析機能」と、

SSHログから総当たり攻撃・辞書攻撃・侵入成功の痕跡を調査する「SSHログ解析機能」の

2つを、ブラウザ上でアップロード・解析・結果表示まで行える構成にしています。



\## 構成



| 機能 | エンドポイント | 内容 |

|---|---|---|

| SSHログ解析機能 | POST `/upload-log` | ログファイルをアップロードし、総当たり攻撃・辞書攻撃・侵入成功を検出 |

| ファイル解析機能 | POST `/upload-folder` | フォルダを選択してアップロードし、メタデータ・ハッシュ値・拡張子偽装を検出 |



CUI版（`bruteforce.js`・`scan.js`）の解析ロジックをそのまま再利用しており、

`module.exports` で関数を切り出すことで、CUIとしての実行（`node bruteforce.js ...`）も

引き続き利用できる形になっています。



\## 動作環境



\- Node.js v24.16.0

\- 使用ライブラリ：Express、multer（ファイルアップロード処理）

\## 使い方



\### 1. SSHログ解析



1\. トップページで、SSHログファイル（`auth.log`形式）を選択する

2\. 「解析開始」ボタンを押す

3\. IPアドレスごとの失敗回数・成功回数・判定結果（正常／警告／危険）が、色分けされたテーブルで表示される



判定は以下の3段階です。



| 判定 | 内容 |

|---|---|

| 🔴 危険（critical） | 失敗が続いた後にログインが成功している（侵入成功の疑い） |

| ⚠ 警告（warning） | 失敗回数が5回以上、または試行ユーザー名の種類数が3種類以上 |

| 正常（normal） | 上記のいずれにも該当しない |



\### 2. ファイル解析



1\. トップページで、調査対象のフォルダを選択する（`webkitdirectory`属性により、フォルダごと選択可能）

2\. 「解析開始」ボタンを押す

3\. ファイルごとの拡張子・サイズ・拡張子偽装の判定結果が、テーブルで表示される



\## CUI版との違い



| 項目 | CUI版（forensic-tool） | Web版（forensic-tool-web） |

|---|---|---|

| 操作方法 | コマンドラインから実行 | ブラウザから操作 |

| 結果の出力 | CSV／JSONファイル | ブラウザ上に表示（色分け済み） |

| 対象の指定 | コマンドライン引数でパスを指定 | ファイル選択ダイアログで指定 |



\## 実装時に発見・対応した課題



\- `multer`でアップロードされたファイルは、デフォルトではランダムな名前で保存されるため、

&#x20; `diskStorage`を使って元のファイル名を保持するよう修正した。

\- 日本語を含むファイル名が文字化けする問題が発生したため、

&#x20; `Buffer.from(originalname, "latin1").toString("utf8")` による変換を行い解消した。



\## テストデータについて



CUI版（`forensic-tool`）からコピーしたものを使用しています。



| フォルダ | 内容 |

|---|---|

| `test\_data/` | ダミーファイル（シグネチャ判定ロジックの確認用） |

| `test\_data\_real/` | 実在するExcel・PDF・テキストファイル（拡張子偽装は意図的にリネーム） |

| `test\_logs/` | Kali Linux から Ubuntu 検証環境への実際のSSH総当たり攻撃実験で取得したログ |

\## 使用にあたっての注意



SSHログの解析検証には、自身が管理する検証環境（Kali Linux／Ubuntu）で取得した

ログのみを使用しています。第三者のシステムへの攻撃・無断アクセスは行っていません。
